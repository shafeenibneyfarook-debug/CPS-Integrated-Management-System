# CPS Management System — Enterprise Contractor Operations & Proposal Bidding Platform

> **Master Operational Architecture & Comprehensive Technical Documentation**  
> *Version 2.4 — A unified full-stack contractor platform orchestrating live material price scraping, automatic inventory synchronization, supplier capacity offers, logistics quantity verification, finance valuations, AI Bangladesh BOQ estimation, resource-based proposal bidding, admin verification, client offer approvals, and mandatory import/export order finance approvals.*

---

## 🌟 Executive Summary & Platform Capabilities (USP)

The **CPS Management System** automates the entire multi-role contractor operational lifecycle:

1. **Admin-Only Firecrawl Live Web Scraper**:
   Live price scraping from BDStall, Akij Cement, BSRM, and Labour Guild is restricted **SOLELY to the Administrator** to capture raw market pricing and flag $>30\%$ anomalies.
2. **Scraped Item Admin Verification & Automatic Inventory Sync**:
   When the Administrator reviews a scraped item and approves its status as `"Verified"`, the system updates the record status in real-time and **automatically synchronizes the verified item into Inventory & Stock (`InventoryItem`)** with item code `SCRAP-XXXXXX`, brand, unit price, and stock levels.
3. **Interactive Google Maps Site Location Picker**:
   Integrated Bangladesh location picker (Dhaka Gulshan-2, Uttara, Chittagong Agrabad, Sylhet Zindabazar, Khulna) displaying GPS coordinates (`lat, lng`) and verified site badges across Quotations, Projects, BOQ Estimator, and Freight Tracking.
4. **Manager Notification & Client Selection for BOQ Offer Bidding**:
   When a Client submits a proposal request, a real-time notification alert is sent to the Manager. Opening the BOQ Estimator displays the Client Proposals dropdown; selecting any proposal **auto-fills all estimation fields & target Client ID** (Project Title, Client, Area SqFt, Floors, Location).
5. **AI Bangladesh Construction BOQ Estimator**:
   Managers execute the AI BOQ Estimation Engine combining live scraped BD market prices with BNBC 2020 structural load standards and regional division factors (Dhaka, Chittagong, Sylhet, Khulna, Rajshahi).
6. **Admin Verification & Client Offer Decision**:
   Manager places an offer bid (`"Pending Admin Approval"`). Admin verifies the offer (`"Admin Verified"`), dispatching a notification alert to the Client. The Client reviews and selects **Accept Offer** or **Decline Offer**. Upon acceptance, the project moves to **Logistics & Operations** for site execution and shipment tracking.
7. **Supplier Material Capacity Offers**:
   Suppliers view verified material listings and submit available supply quantities (`availableQuantity`) they can provide.
8. **Logistics Officer Quantity Verification**:
   Operations Logistics Officers inspect supplier quantity offers and confirm physical feasibility (`"Logistics Verified"`). Confirmed quantities auto-update stock levels in Inventory.
9. **Mandatory Import & Export Order Finance Approvals**:
   All import/export landed cost calculations, foreign currency duty valuations, and customs clearances must go through the **Unified Head of Finance** (`"Pending Finance Approval"` -> `"Finance Approved"`).
10. **Single Unified Head of Finance (`accounts_officer`)**:
   Company finances, project invoice approvals, and import/export duty approvals are assigned to **one unified lead person — the Chief Financial / Unified Head of Finance**. Every new Manager invoice is linked (`financeOfficer`) and routed directly to this unified financial officer for verification.
11. **Project-Specific Invoice Notifications for Finance Role**:
   Every new Manager-generated invoice immediately dispatches a **Project-Specific Notification Alert** to the Unified Head of Finance, specifying the project name, site location, invoice number, and monetary valuation.
12. **Permanently Visible Role Notification Center & Dynamic Count Decrementing**:
   A topbar header **Notification Bell Icon (`🔔`)** is permanently visible across all 6 roles, featuring dynamic unread count decrementing on read, individual card dismissal ("✕"), and "Mark all read" controls with per-user local storage tracking (`cps_seen_notifs_${userId}`).
13. **Manager Invoicing -> Finance Verification -> Client Dashboard Payment**:
   Invoices generated by the Manager are submitted for Accounts/Finance verification (`"Pending Finance Verification"`). Accounts Officers verify the invoice (`"Finance Verified"`). Verified invoices automatically populate on the **Client Dashboard & Invoice Portal** for online payment.
14. **Production Enterprise Homepage Footer**:
   Integrated market intelligence newsletter subscription, Gulshan-2 HQ hotline (`+880 9612-000000`), live system operational status (`Dhaka Server East-1 99.9% Uptime`), BNBC 2020 compliance badges, and 256-bit security standards.

## 🔄 Master Operational Lifecycle Workflow

```
 [1. Client Proposal Request & Google Map Location]
        │
        ├──> Client Submits Building Proposal Request with Google Map Location & Coordinates
        │
 [2. Real-Time Manager Notification & Client Selection BOQ Estimator]
        │
        ├──> Manager Receives 🔔 Notification Alert -> Selects Client Proposal -> Auto-fills All Fields + Client Reference -> Submits Offer
        │
 [3. Admin Verification & Client Decision Notification]
        │
        ├──> Admin Verifies Manager's Offer ("Admin Verified") -> Client Receives 🔔 Notification -> Selects "Accept Offer" or "Decline Offer"
        │
 [4. Admin Review of Scraped Prices & Automatic Inventory Sync]
        │
        ├──> Admin Reviews Scraped Items -> Sets Status to "Verified" -> Item Auto-Syncs to Inventory & Stock Registry (SCRAP-XXXXXX)
        │
 [5. Import & Export Duty Finance Approval]
        │
        ├──> Import/Export Landed Cost Calculations Submitted -> Unified Head of Finance Reviews & Approves ("Finance Approved")
        │
 [6. Logistics & Operations Execution Notification]
        │
        ├──> Approved Proposal Handed Off to Operations Officer for Site Material Allocation & Freight Tracking
        │
 [7. Manager Invoicing & Unified Head of Finance Verification to Client Dashboard]
        │
        ├──> Manager Generates Invoice -> Unified Head of Finance Receives Project-Specific 🔔 Notification -> Verifies & Approves ("Finance Verified") -> Displays on Client Dashboard for Online Payment
```

```bash

npm start
```
*Backend runs on `http://localhost:5001`. Configure `FIRECRAWL_API_KEY` in `server/.env`; never commit the key.*

### 2. Client Setup & Launch
```bash
cd client
npm run dev
```
*Frontend runs on `http://localhost:5173`.*
