# Backend for CPS Integrated Management System

## Setup

1. Install dependencies
   ```bash
   npm install
   ```
2. Configure environment variables in `.env`
3. Start the API server
   ```bash
   npm run dev
   ```

## Available API endpoints

- GET /api/clients
- POST /api/clients
- PUT /api/clients/:id
- DELETE /api/clients/:id
- GET /api/suppliers
- POST /api/suppliers
- PUT /api/suppliers/:id
- DELETE /api/suppliers/:id
- GET /api/projects
- POST /api/projects
- PUT /api/projects/:id
- DELETE /api/projects/:id
